## Alloy development environment

The repository does not currently include application source or build instructions. Its Alloy environment serves a static repository-status page so the workspace has a reproducible, verifiable frontend until source is checked in.

Start the preview with:

```sh
docker compose -f docker-compose.alloy.yaml up -d
```

The site listens on `http://localhost:3000`. Alloy proxies this port through its session preview.
